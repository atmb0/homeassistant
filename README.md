# Home Assistant

Public, shareable Home Assistant configuration. Everything here is sanitized: no credentials, tokens or private devices.

## Contents

| Folder | Description |
|---|---|
| [`dashboards/lisboa-porto-cams`](dashboards/lisboa-porto-cams) | Public live cameras and traffic images for Lisbon and Porto. The airport player follows the daily live via a Scrape sensor; Windy images show their capture time. Includes install steps, troubleshooting and a changelog |

## Layout

```
dashboards/   Lovelace dashboards (raw config YAML) + required helpers, one folder each
```

More folders (e.g. `automations/`, `scripts/`, `blueprints/`) can be added as needed.
